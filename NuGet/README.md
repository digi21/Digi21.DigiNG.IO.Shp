# Digi21.DigiNG.IO.Shp

This package contains a reference assembly with types for reading/creating Shapefile files (*.shp)

The runtime assemblies are installed by [Digi3D.AI](https://www.digi21.net/Digi3D). The Digi21.DigiNG package, which this package depends on, adds a source file to your C# project that locates them in the Digi3D.AI installation folder, so your console application or extension can be installed in any folder. You do not have to add any other package or write any code.

A Digi3D.AI license is required to run applications that use the assemblies published by this package. [Rent](https://www.digi21.net/Tienda/Alquiler) or [buy](https://www.digi21.net/Tienda/Compra) a license.
